Fragrance Trends MCP

A Model Context Protocol server for fragrance trend intelligence. This is a machine endpoint, not a web application.

Endpoint

POST /api/mcp
Authorization: Bearer <api key>
Content-Type: application/json

Status

GET /api/mcp returns the server mode, tool count and operating caveats.

Client configuration

{
  "mcpServers": {
    "fragrance-trends": {
      "url": "https://<your-deployment>/api/mcp",
      "headers": { "Authorization": "Bearer <api key>" }
    }
  }
}

What it exposes

  • Ten tools spanning trending fragrances and ingredients, regional demand, velocity, lifecycle, emerging signals, market gaps, launches, search and reporting.
  • Every response carries a provenance envelope: sources, observation timestamp, cache staleness, and whether numbers were measured or modelled.
  • An integrity guard rejects fabricated-looking numeric distributions rather than returning them.
  • Per-tenant plan gating, rate limits and cost-unit budgets.
Operating posture. This deployment serves dated fixture snapshots, not live data, and its metering is per-instance rather than a billing ledger. Licensed live mode fails closed until data resale rights, durable tenant isolation and persistent metering are in place.
